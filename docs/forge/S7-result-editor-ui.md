# S7 — 결과 에디터 UI (+ 설정 화면)

## 목표
처리 완료 시 **원본 vs 결과 diff 하이라이트**, `[교체][복사][다시 생성][취소]` 버튼, 편집 가능한 **결과 에디터**와, 모델/하드웨어/프롬프트/핫키를 다루는 **설정 화면**을 만든다.

## 배경 (레포 기준)
- `src/Forge.App/` 존재(S5). S4 코어·S6 오버레이 전제.
- 근거: plan §4(결과 에디터, 설정 화면), §5(ReplaceAction — 교체는 S11).

## 결정
- 결과 에디터: 스트리밍 중 raw text → 완료 시 diff 렌더(plan §4). 분할 뷰, 편집 가능.
- 버튼: 교체(S11 위임), 복사(클립보드), 다시 생성(S4 재호출), 취소.
- 설정 화면: 모델 선택(카탈로그, S9 연동)/정밀도/ctx, 하드웨어(CPU/GPU/Auto, S8 연동), 프롬프트 편집, 핫키 바인딩(S6 연동).
- 이 유닛은 **UI 레이아웃 + 상태 표시** — 교체 로직(S11), 다운로드(S9), 감지(S8)는 각 유닛.

## 작업
1. 결과 에디터 윈도우: 분할 뷰 + diff 하이라이트(라이브러리: DiffPlex 등).
2. 버튼 바인딩: 복사/다시 생성/취소 즉시, 교체는 S11 이벤트 노출.
3. 설정 화면: 탭/섹션 구성, 각 항목은 S6·S8·S9 모델 바인딩.
4. 스트리밍 → 완료 전환 UX.
