# S12 — 로버스트니스: 재진입·에러·crash dump·클립보드 복원 (M5)

## 목표
**재진입 가드**, 일관된 **에러 처리**, opt-in **최소 crash dump**(텍스트 제외), **클립보드 복원**을 앱 전체에 걸친 로버스트니스로 완성한다.

## 배경 (레포 기준)
- `src/Forge.App/`·`src/Forge.Core/` 존재. S5(셸)·S7(에디터) 전제.
- 근거: plan §7(네이티브 크래시 — try/catch 구제 불가, opt-in crash dump), §4(비파괴적, 클립보드 백업/복원), 재진입 가드.

## 결정
- 네이티브 하드크래시는 **앱 종료 전제**(plan §7) — crash dump로 원인만 기록(스택+모델+타임스탬프, **텍스트 내용 제외**).
- .NET 측 예외는 일관된 에러 UX(사용자 안내 + 복구 경로).
- 재진입 가드: 처리 중 핫키/이중 추론 차단(S6와 연계).
- 클립보드 백업/복원은 모든 교체·복사 경로에 공통.

## 작업
1. 전역 예외 핸들러 + opt-in crash dump(텍스트 제외) 기록.
2. 에러 UX: 캡처 실패/ctx 초과/모델 로드 실패/교체 실패별 안내 + 복구.
3. 재진입 가드 통합(S6·S4).
4. 클립보드 백업/복원 공통 유틸(S11·S7 공유).

## 하지 말 것
- 텍스트 내용을 로그에 남김 — 프라이버시 위반(plan §4).
- 네이티브 크래시 "구제"를 약속 — 안 함(종료 전제, plan §7).
- 텔레메트리/외부 전송 — 향후.

- [ ] 의도적 OOM/로드 실패 → crash dump 기록(텍스트 없음) + 앱 재기동 안내.
- [ ] 각 에러 경로가 사용자 안내 + 복구로 끝남(멈춤/크래시 아님).
- [ ] 처리 중 재진입 차단 확인.
- [ ] 모든 교체/복사 경로에서 클립보드 백업/복원.
