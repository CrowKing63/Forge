# S6 — 작업 선택 오버레이 + 핫키

## 목표
글로벌 **핫키**를 등록하고, 팝업형 핫키 시 **작업 선택 오버레이**(변역/재작성/교정/요약)를 표시·선택하는 UI를 만든다.

## 배경 (레포 기준)
- `src/Forge.App/` 존재(S5). S4 코어 전제.
- 근거: plan §4(핫키 설계, 작업 선택 오버레이), §7(재진입 가드).

## 결정
- 글로벌 핫키: `RegisterHotKey`(Ctrl+E 팝업형, Ctrl+E+1/2 즉시형 — 설정에서 바인딩).
- 오버레이: 소형 팝업, 4작업(변역/재작성/교정/요약), 키보드 내비게이션(↑↓+Enter), Esc 취소.
- 선택 즉시 처리 시작(S4 파이프라인 호출).
- **재진입 가드:** 처리 중 핫키 무효화(plan §7).

## 작업
1. 글로벌 핫키 등록/해제 (설정에서 추가 즉시형 핫키 대응).
2. 오버레이 윈도우: 4작업 표시, 키보드 내비게이션, Esc.
3. 선택 → S4 E2E 호출(처리 시작).
4. 재진입 가드: 처리 중 중복 핫키 무시.

## 하지 말 것
- 결과 에디터 — S7.
- 교체 로직 — S11.
- 설정 UI 자체 — S7에서(여기서는 핫키 바인딩 읽기만).
- 톤 변경 작업 구현 — 향후(v1은 4작업).

## 검증
- [ ] Ctrl+E → 오버레이 표시, ↑↓+Enter로 선택, Esc 취소.
- [ ] 선택 시 처리 시작(결과는 S7 영역으로 넘어감 — 여기서는 호출 확인만).
- [ ] 처리 중 재핫키 무시(재진입 가드).
