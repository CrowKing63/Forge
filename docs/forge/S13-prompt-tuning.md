# S13 — 프롬프트 튜닝 + 한국어 eval 세트 (M5)

## 목표
4작업 프롬프트를 **한국어 품질** 기준으로 튜닝하고, 회귀를 잡는 **eval 세트를 고문**한다.

## 배경 (레포 기준)
- `src/Forge.Core/PromptBuilder.cs` 존재(S3). S4 코어 전제.
- 근거: plan §5(프롬프트 설계), §7(한국어 품질 — 직접 테스트로 선별, 리스크 낮음), §8(M5 프롬프트 튜닝).

## 결정
- eval 세트: 한국어 교정/변역/재작성/요약 각 N문장 + 기대 결과(수동 라벨).
- 기준: 일관된 한국어, 의미 보존, 절단/영어 누출 없음. (S0의 5문장 샘플을 확장)
- 모델은 기본 Gemma 4 E2B 선별 전제(plan §7) — 여기서는 프롬프트 최적화만.

## 작업
1. eval 세트 정의(한국어 샘플 + 기대 결과).
2. 콘솔/스크립트로 eval 실행 → 현재 프롬프트 대비 품질 비교.
3. 프롬프트 튜닝(PromptBuilder) — 의미 보존·절단 방지 지시 강화.
4. 회귀: eval 통과 기준 설정, 변경 시 재실행.

## 하지 말 것
- 모델 교체/업그레이드(E4B 등) — 향후(plan §7).
- 자동 라벨링/학습 기반 튜닝 — 안 함(수동 라벨만).
- 다국어 eval 확장 — 향후(v1 한국어 중심).

## 검증
- [ ] eval 세트 전체에서 품질 기준 충족(의미 보존·절단 없음).
- [ ] 프롬프트 변경이 회귀를 일으키지 않음(eval 재통과).
- [ ] 4작업별 대표 샘플이 개선 확인.

## 산출물
- eval 세트 + 튜닝된 프롬프트 (M5 완료)
